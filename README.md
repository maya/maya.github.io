# Maya Benari Portfolio

A finished static portfolio concept built around:
- editorial hierarchy
- forward-looking digital material
- meaningful systems structure
- Maya's public body of work

## Files
- `index.html`
- `styles.css`
- `script.js`

## Run locally
Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
- The enterprise project visual is intentionally abstract so it does not expose confidential product UI.
- The hero illustration is pure CSS, so there are no external art assets to manage.
- Google Fonts are loaded from the web. For a fully offline build, swap them for system fonts.
- Contact/social URLs should be updated to the exact profiles you want to use before deployment.
